# Vendored assets (`web/`)

Fonts under `public/fonts/` are copied from the classic admin UI
(`server/src/tessera_server/ui/static/fonts/`) for the React console.

- `fonts/Manrope-Variable.woff2` — Manrope (SIL Open Font License 1.1),
  https://github.com/google/fonts/tree/main/ofl/manrope
- `fonts/IBMPlexMono-Regular.woff2`, `fonts/IBMPlexMono-Medium.woff2` —
  IBM Plex Mono (SIL Open Font License 1.1),
  https://github.com/google/fonts/tree/main/ofl/ibmplexmono

npm dependency licenses are checked separately by `npm run check:licenses`
(MIT / ISC / BSD / Apache-2.0 allow-list).
