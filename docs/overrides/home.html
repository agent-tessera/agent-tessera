Agent Tessera

Default-deny permissions and a tamper-evident audit log for AI agents, whatever LLM they call.

Python · Apache 2.0

Read the quickstart PyPI

What it decides, before the call runs

Default deny

Anything the policy does not allow is denied before the function runs. One decision order, documented and tested.

Tamper-evident audit

Every decision is hash-chained. tessera audit verify catches an edit after the fact.

In your process

No network call per decision. The optional server adds registration, signed bundles, a kill switch, and a console.

A policy a reviewer can read

apiVersion: tessera/v1
kind: AgentPolicy
metadata:
  agent: demo
spec:
  tools:
    allow: ["files.read"]

Mark a tool, or wrap the LLM client. files.read runs. shell.run is blocked, and the denial is in the log.

$ tessera audit verify .tessera/audit.jsonl
OK: 5 events
